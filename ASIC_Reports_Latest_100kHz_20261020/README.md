fast/slow clock definitions coexist in adaptive STA, while power uses the
actual simulated processing activity. Large positive setup slack at this
clock rate is not a maximum-frequency measurement.

## Conditions and checks

- Technology: generic GPDK045 / gsclib045 SVT standard cells, not a 45 nm FPGA.
- Power: routed average estimate, slow library at 0.9 V / 125 C; actual native
  TCF activity from functional gate simulation without SDF.
- Timing: slow 0.9 V / 125 C and fast 1.1 V / 0 C views. Both use the same
  reference QRC technology at their respective temperatures, not independently
  qualified RC best/worst corners. Actual clock waveform and retained IO
  assumptions are recorded in the SDC; IO/reset/CDC assumptions still matter.
- Input: identical synthetic normal signal, 120 samples/s; 10 s warm-up and
  60 s measurement. Both accept all 8400 samples without overflow, produce
  60 measured Stage 1 results and no Stage 2 results, and match all 66
  classification IDs/codes and measurement-membership flags. Latencies differ.
- Activity: 100% primary-input, flop-output and power-net annotation, with
  complete real-net routed RC coverage in both cases.
- Both pass routed setup/hold and electrical checks, 562 selected default
  external DRC rules and transistor-level LVS with no blackboxes. The single
  enabled antenna rule also passes.
- Includes clock controller, mailbox and routed clock trees. Excludes external
  clock generation and pad/board power; no delay-dependent glitch estimate.
- This is a research implementation, not foundry/manufacturing sign-off,
  fabricated-silicon power, clinical duty-cycle power, DFT closure or formal
  RTL equivalence. Comprehensive antenna/density/DFM/EMIR remain outside scope.

The gated slow clock passes a full 5 us source pulse once per 200 cycles
(500 rising edges/s), rather than making a 50%-duty square wave. Stage 2 can
request 100 kHz when active; that active condition is not measured here.
